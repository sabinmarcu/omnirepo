### !!project Whitelabel Design System

#### Design system complet personalizabil pentru fiecare partener

* Permite personalizarea completă, de la culorile de brand și sistem până la maparea semantică a variabilelor către fațetele componentelor
* Construit integral cu Vanilla Extract pentru a scrie cod complet type-safe și pentru a expune doar CSS generat la momentul build-ului
* Folosește pachetul ESLint Logical Properties și React ARIA pentru accesibilitate.

#### Flux unificat de la UX la Dev

* Variabilele de design și mapările de variabile pentru primary color -> surface background sunt importate direct din figma
* Variabilele, mapările și contractele sunt integrate direct în pachetele publicate
* Devii folosesc variabile semantice și nu au acces la primitive sau mapări
* Funcții de export asociate cu CSS layers pentru a fi folosite de DS sau aplicații

#### Folosește cele mai recente tehnici CSS

* Folosește CSS Layers pentru a delimita straturi clare de cascadă între reset, colecțiile de variabile, framework (design system) și stilurile aplicației.
* Folosește CSS Containers pentru a încapsula stilurile și a crea componente și layout-uri cu adevărat responsive
* CSS Variables și culorile și mapările specifice partenerilor sunt calculate și randate pe server
