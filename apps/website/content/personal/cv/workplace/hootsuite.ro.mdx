### !!project Mono CLI System

* CLI System inspirat atât de ESLint, cât și de React / ReactDOM
* Le permite dezvoltatorilor să creeze cu ușurință comenzi CLI și Configs inspirate de ESLint, publicabile pe NPM, printr-un SDK type-safe, intuitiv și configurabil (CLI SDK)
* Le permite consumatorilor fie să importe un CLI preconstruit (sau parțial construit), fie să își construiască propriul CLI din blocuri de construcție disponibile pe NPM (CLI Core)
* Comenzile sunt blocurile de construcție (React Components)
* Configs sunt CLI-uri construite complet (sau parțial) din Commands
* Dacă „Folosești o bibliotecă pentru a scrie cod care face lucruri, iar un framework îți folosește codul pentru a face lucruri”, atunci Mono este ambele
* Folosești React pentru a crea o aplicație și ReactDOM pentru a o randa
* Folosești CLI SDK pentru a crea Commands și Configs, iar CLI Core pentru a construi un CLI funcțional din Commands și/sau Configs
