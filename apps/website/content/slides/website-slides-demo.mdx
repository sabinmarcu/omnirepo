# !!slide Welcome to website slides

A burgundy-native deck authored in MDX. **Read** is the canonical long-form view, **Present** adds navigation when requested, and **Print** is a static browser-print handout.

| View | Best for |
| --- | --- |
| Read | Links and careful reading |
| Present | A live talk |
| Print | Browser Print or Save as PDF |

## !notes

Open in Read first: the same content is already useful before presentation JavaScript loads.

# !!slide CodeHike annotations

Filename, line numbers, marks, diffs, and folds remain useful static evidence in Read and Print.

```ts slide-policy.ts
export function chooseView(requested: 'read' | 'present' | 'print') {
  // !mark
  const serverRendered = true
  // !diff -
  return { serverRendered, runtime: 'always' }
  // !diff +
  return { serverRendered, runtime: requested === 'present' ? 'reveal.js' : 'none' }
  // !fold[/^\s*\/\/ Internal/]
  // Internal implementation details stay expanded in static views.
}
```

## !notes

Point out that annotation semantics come from the existing CodeHike pipeline, not a second highlighter.

# !!slide Presenting and sharing

Each slide keeps the anchor emitted by the MDX heading pipeline, so a Read URL with that fragment can identify a specific slide. Present includes speaker notes; Read and Print intentionally do not.

For a handout, open **Print** and use the browser's **Print** or **Save as PDF** command. This deck does not create or download a PDF.
